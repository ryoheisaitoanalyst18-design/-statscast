statscast uploader プライバシーポリシー

最終更新日: 2026年10月29日

statscast uploader（以下「本アプリ」）は、ROKUDAI STATCAST の運営者が自分の YouTube チャンネルに 試合動画をアップロードするためだけに使う、個人用のツールです。一般の利用者には提供していません。

1. 利用する情報と使い方

本アプリは YouTube API サービスを利用し、運営者本人が許可した Google アカウントについてのみ、次のことを行います。

  • 運営者の YouTube チャンネルへの動画のアップロード（限定公開）
  • アップロードした動画の処理状況・公開設定・再生できるかどうかの確認、チャンネル名の表示

運営者以外の方の情報を取得することはありません。取得した情報を広告・販売・他の目的に使うことはありません。

2. 保存と共有

Google の認証情報（アクセストークン）は運営者のパソコンの中にだけ保存し、外部のサーバーには送信・保存しません。 取得した情報を第三者と共有することはありません。

3. アクセス許可の取り消し

本アプリへのアクセス許可は、 Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。

4. YouTube API サービスについて

本アプリは YouTube API サービスを使用しています。本アプリの利用には YouTube 利用規約が適用されます。 Google による情報の取り扱いについては Google プライバシー ポリシーをご覧ください。

5. お問い合わせ・変更

お問い合わせは 運営者の GitHub までお寄せください。 本ポリシーを変更する場合は、このページを更新します。
